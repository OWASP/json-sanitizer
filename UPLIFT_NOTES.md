# Modernization summary

The modernization shipped in [1.3.0](https://github.com/OWASP/json-sanitizer/releases/tag/v1.3.0)
on November 7, 2026 as `org.owasp.json-sanitizer:json-sanitizer`.
It added Java 8 compatibility, bounded stream input, security and correctness
fixes, current CI and Central Portal publishing.

- [Changelog](CHANGELOG.md): released changes.
- [Getting started](docs/getting_started.md): installation and migration.
- [Release guide](docs/RELEASING.md): current publishing procedure.
- [Modernization archive](docs/modernization/README.md): historical decisions,
  review findings and validation evidence, including the
  [original phase notes](docs/modernization/UPLIFT_HISTORY.md).

The archive's pending tasks and tool versions describe the work at the time;
they are not a current backlog or a requirement to continue modernization.
